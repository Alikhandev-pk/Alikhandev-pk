## About Me

I'm **Ali Khan**, a full-stack developer and founder of **Brandox Digital**, based in Peshawar, Pakistan. I build e-commerce websites and business software, with a focus on ERP and point-of-sale applications.

- **Client work:** Storefronts, product catalogs, checkout flows, and admin dashboards
- **Business software:** POS and ERP applications for retail and pharmacy workflows
- **Currently building:** Brandox Pharma POS

## Engineering Approach

- Start with the business workflow and map it to the screens people use every day.
- Build admin tools alongside customer-facing features so businesses can manage their own products, orders, and content.
- Use role-based access to give each user the permissions their work requires.
